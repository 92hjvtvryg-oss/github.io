# Moonpage

Mijn persoonlijke portfolio, gemaakt met HTML, CSS en JavaScript.

## Bekijken op je eigen computer

Dubbelklik op `index.html`.

## Waar pas je wat aan?

| Wat | Waar |
| --- | --- |
| Teksten, in elke taal | `translations.js` |
| Kleuren en lettertypes | bovenaan `style.css` |
| E-mailadres | bovenaan `script.js` (`CONTACT_EMAIL`) |
| Een nieuwe taal | `translations.js` (uitleg bovenaan dat bestand) |
| Een mini-tool koppelen | kopieer `tools/template.html` en vul `data-tool` in bij de kaart in `index.html` |

## Gratis online zetten met GitHub Pages

1. Maak een account op [github.com](https://github.com).
2. Maak een nieuwe repository aan met **New repository**. Kies **Public** als zichtbaarheid.
3. Klik op **uploading an existing file** en sleep alle bestanden uit deze map erin, inclusief de map `tools`.
4. Klik op **Commit changes**.
5. Ga naar **Settings → Pages**. Kies bij **Source** voor **Deploy from a branch**, en daarna voor **main** en **/ (root)**. Klik op **Save**.
6. Na een paar minuten staat je site op `https://JOUW-GEBRUIKERSNAAM.github.io/NAAM-VAN-REPOSITORY/`.

Tip: noem je repository `JOUW-GEBRUIKERSNAAM.github.io`, dan is het adres korter: `https://JOUW-GEBRUIKERSNAAM.github.io/`.
